# Copilot Project Submission

This repository contains the final project for the Udacity course. The project demonstrates the use of Copilot to automate tasks and generate deliverables for supply chain management and compliance.

## Included Files and Purpose

- `prompts/`  
  Contains the documented Copilot prompts for each task. Each file describes the prompt used, its purpose, and the expected output.

- `outputs/`  
  Organized by task folders. Each folder contains the deliverables generated for that task.
  - `Task1/`
    - `Supply_Chain_Issues_Review.docx`: Comprehensive review of urgent supply chain issues impacting FDA compliance. Includes analysis of component disruptions, quality control failures, and recommended action items.
      
- `Task2/`
    - `Supply_Chain_Issues_Review Teams Meeting.docx`: Meeting invite and agenda for the Supply Chain Issues Review, listing participants, topics, and action items to address supply chain risks
 
      
 `Task3/`
    - `Supply_Chain_Insights.xlsx`: Excel file containing supply chain risk assessment data. Includes analysis of average delivery timelines by risk level, on-time delivery rates for delayed components (CARB123, BIND567, COAT890), and a supplier performance breakdown.[1]
    - `Supply_Chain_Issue_Analysis_Report.docx`: Professional report based on the Excel analysis. Includes executive summary, component overview, compliance implications, root cause analysis, and both general and component-specific mitigation strategies.[2]

  - `Task4/`
    - `Supply Chain Issue Compliance Report.pptx`: Professional stakeholder presentation summarizing supply chain compliance issues, risks, and mitigation strategies. Includes executive summary, agenda, data visualizations, component and supplier analysis, compliance implications, root cause analysis, and recommended actions



## Overview of Tasks and Deliverables

- **Task 1:**  
  Analyze and summarize supply chain issues from recent communications. Deliverable: `Supply_Chain_Issues_Review.docx` (Word document with business problem, action items, and conclusion).

- **Task 2:**  
  Meeting invite, agenda, and action plan for supply chain review. Deliverables: Meeting invite, agenda, Action Items Plan.

- **Task 3:**  
Supply chain risk assessment and analysis report. Deliverables: Risk assessment data and analysis report.

- **Task 4:**  
Stakeholder presentation with speaker notes and data visualizations. Deliverable: Compliance report presentation.
